# EriseChat 使用说明

> 面向最终用户的安装与日常使用说明（适用版本 **1.2.0**）。服务器部署与升级见 [docs/deploy.md](deploy.md)、[docs/update-deploy.md](update-deploy.md)；仓库约束见 `AGENTS.md`。
> 本工具**不提供端到端加密（E2EE）**：服务端可见消息内容，请勿用于传递敏感信息。

## 1. 获取安装包

安装包由部署者提供，或从服务端的下载页 `https://<你的域名>/download` 获取。当前版本为 1.2.0：

- Windows：`EriseChat-Setup-1.2.0.exe`（NSIS 安装包，免代码签名）
- Android：`EriseChat-1.2.0.apk`（侧载安装，不上架应用商店）

文件大小与 SHA256 见 [docs/desktop.md](desktop.md) §1 / [docs/mobile.md](mobile.md) §1，下载后建议核对哈希。**1.1.0 及更早的历史安装包已废弃，不再出现在下载页，也不作为回滚路径。**

## 2. 安装

**Windows**：双击安装包，出现 SmartScreen「Windows 已保护你的电脑」时点「更多信息 → 仍要运行」——这是未购买代码签名证书的正常提示，不是安装包损坏。向导默认「当前用户」安装，无需管理员权限。

**Android**：在「设置 → 安全 → 安装未知应用」中允许所用浏览器或文件管理器后，打开 APK 完成安装。

> **从 1.1.0 及更早版本升级**：1.2.0 起应用标识（Windows `appId` / Android `applicationId`）已变更，系统视为新应用，需**先卸载旧版再安装新版**。本机设置、草稿与缓存会清空；旧版曾保存的明文记密记录会在新版首次启动时清除，**服务端聊天记录不受影响**。详见 [docs/desktop.md](desktop.md) §2.1 与 [docs/mobile.md](mobile.md) §2.1。

## 3. 首次登录

1. 启动应用。打包态登录页会显示「服务器地址」区块，填写部署者提供的地址（例如 `https://<域名>`），点「保存并检测」显示可达后继续；Web 同源部署不显示该区块。
2. 新用户切「注册」→ 填写邮箱 → 发送验证码 → 填写昵称与 6 位验证码完成注册。
3. 已有账号可用验证码登录或密码登录。应用不保存登录密码；如需免输入请使用浏览器/系统密码管理器（密码框保留密码管理器所需的自动填充属性），公共设备请勿让浏览器记住密码。
4. 忘记密码可在登录页通过邮箱验证码重置。

> 1.2.0 上线后**所有用户需重新登录**（JWT 签发方与受众变更，旧令牌失效）。

## 4. 日常使用

- 单聊与群聊；发送文本、图片、文件、语音消息；断线或重新打开应用会自动补拉历史消息。
- 右键（Windows/Web）或长按（Android）消息可回复、转发、撤回（发送后 2 分钟内）、编辑（文本，15 分钟内）、收藏；「多选」最多选择 20 条消息批量转发。
- 左导航与聊天顶栏提供全局搜索、会话内搜索；「设置」可修改头像/昵称、登录密码、通知与提示音、服务器地址。
- 收藏保存在服务端，同账号在 Web / Windows / Android 上跨设备同步。
- Android 可在「设置 → 消息提醒 → 后台消息提醒」开启后台提醒：由前台服务在后台保持连接并发送系统通知，受 **Android 15+ 单日 6 小时**限制，**系统重启后需重新开启**；免打扰会话与自己发送的消息不提醒。
- 「设置 → 关于 → 检查更新」可查询服务端是否有更新版本；Web 浏览器仅提示刷新页面。

## 5. 重要边界

- 无系统级离线推送：应用未运行或标签页关闭时新消息不即时提醒，重新打开后靠补拉同步。
- 聊天记录以服务端为唯一事实源；本机缓存（IndexedDB / localStorage）清空后可从服务端重新同步。
- 不提供 iPhone / iOS 客户端；本期不做语音/视频通话、朋友圈、AI 与机器人功能。
- 账号、消息与文件保留在部署者自己的服务器上；应用不保存登录密码，公共设备请勿让浏览器记住密码。
