# EiseChat UI 参考资产

本目录存放 UI 改造相关的参考图与基线截图（V1.1 起），与 [`../ui-upgrade-plan.md`](../ui-upgrade-plan.md) 配套。

| 目录/文件 | 用途 | 产出阶段 |
|---|---|---|
| `参考图`（本目录，可放子目录） | 客户提供的视觉参考图（桌面/移动各自命名） | 用户提供 |
| `screens-before/` | 改造前基线截图（登录、会话列表、聊天、联系人、群聊、设置） | UI-00-06 |
| `screens-after/` | 改造后对比截图（与 before 同视角） | UI-05 |

约定：

- 文件命名：`<序号>-<页面>-<端>.png`，例如 `01-聊天-桌面.png`、`02-会话列表-移动.png`；
- 截图不得包含真实账号、token、验证码、服务器密钥、内网地址等敏感信息（用测试账号与脱敏数据）；
- 参考图仅作为视觉方向参考，不以像素级复制为目标（见计划 §0.2 D-01）。
